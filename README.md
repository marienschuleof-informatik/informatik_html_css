# 🌐 Lebenslauf – Web Project

A personal CV website built with HTML, CSS and JavaScript — developed as part of a structured four-module web development course.

**AI Transparency Statement**
All content in this repository was generated using AI tools and has been carefully reviewed, edited, and pedagogically curated by the author. The use of artificial intelligence reflects a commitment to responsible, transparent, and reflective integration of digital tools in educational practice.

---

## 📋 Project Overview

This project is a step-by-step introduction to frontend web development. Starting from a bare HTML skeleton, the project grows module by module into a fully accessible, styled and interactive personal CV webpage.

|Module|Topic|Files|
|---|---|---|
|Module 1|HTML structure & hypertext basics|`index.html`|
|Module 2|CSS styling & layout|`style.css`|
|Module 3|JavaScript interactivity|`script.js`|
|Module 4|Accessibility & semantic HTML5|all files|

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ♿ Accessibility

This project follows the **WCAG 2.1 AA** guidelines:

- `lang="de"` attribute on `<html>`
- Colour contrast ratio ≥ 4,5:1 (verified with [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/))
- All images include descriptive `alt` attributes
- Font sizes in relative units (`em`)
- Full keyboard navigation (Tab + Enter)
- Semantic HTML5 elements throughout
- ARIA labels where appropriate
